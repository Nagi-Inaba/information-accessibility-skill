# Natural-language review example

Use this path when you want a first-pass review before creating a standards ledger or audit run.

```text
Review the named target for information accessibility.
Separate:
1. barriers observed from the available target evidence,
2. improvement ideas,
3. items that require external human verification,
4. the limits of the inspection environment.

Target: https://example.com/
Audience: people using keyboard navigation, screen readers, magnification, captions, and simplified language.
Do not treat missing evidence as a pass and do not make a conformance claim.
```

A useful response should cover the information journey—find, receive, understand, participate, and continue—and should identify which observations are limited screening evidence. For a Web standards audit, continue with either the [standalone assessment](../standalone-ledger/README.md) or the [run-backed audit](../run-backed-web-audit/README.md).
