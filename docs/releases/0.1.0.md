# 0.1.0 — 初回配布候補

公開前の候補です。package版だけでは履歴中の開発版を区別できないため、配布時は生成されたsource commitとSHA-256一覧を併記します。

## 含まれる機能

- Codex／Claude向けのスキル、既定4役割のagent、任意のauthorized fixer。
- WCAG 2.2 A/AAの55項目と、JIS 38項目・追加WCAG 18項目を区別した監査台帳。
- 対象と保存証拠の照合、axe結果の取り込み、人手レビューの記録、監査状態と次の操作の表示。
- 通信範囲・操作承認の強制、人手レビューと監査bundleの外部署名検証。
- 日英Markdown／HTMLレポート、出典・利用条件の帰属表示と更新時の検証。

## 互換性と残る制限

[対応版と移行方針](../version-support.md)および[CHANGELOG](../../CHANGELOG.md)を参照してください。run 14.0.0／registry 13.0.0、screening 4.0.0、queue 3.0.0、assessment 2.0.0、human review／review record 3.0.0、remediation plan 3.0.0を新規形式とし、旧記録は定められた範囲で読取りに対応します。旧runや署名を自動変換する移行ツールはありません。

自動検査とAIの観測は適合の認証ではありません。本番の信頼方針・署名者・鍵、実機支援技術での検査、第三者資料の具体的な再配布に必要な法的判断は配布物が自動で提供しません。対応外の状態付きUI操作や非Web規格を、検査済みとして扱わないでください。

## 配布物の確認

生成する配布物は `information-accessibility-skill-0.1.0-<commit12>.tar.gz`、`source-manifest.json`、`release-notes.md`、`SHA256SUMS`です。manifestで完全なcommit、アーカイブのhash、収録ファイルを確認できます。hash一覧そのものは第三者による署名や出所の保証ではないため、受領経路も確認してください。

実行依存関係は同梱せず、package.jsonで固定しています。リポジトリの.git、node_modules、非公開audit-runs、研究用原本、内部作業記録は配布対象にしません。既定の導入は読取り主体の4agentで、fixerは明示的な選択が必要です。
