# Deterministic `scan-web` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a deterministic `accessibility-audit scan-web` pipeline that runs axe-core and bounded browser probes before AI interpretation, producing a full internal scan and a compact AI context.

**Architecture:** Reuse one Playwright browser session for URL/network policy, DOM/AX evidence, axe-core execution, focus sampling, and reflow probing. Keep the resulting `automated-web-scan` outside the orchestration registry in this slice, so deterministic scanner provenance is not misrepresented as an AI-produced screening artifact. Add a manual read-only GitHub Actions entry for the first real public-URL inspection.

**Tech Stack:** Node.js 20+, ECMAScript modules, Playwright 1.62.1, axe-core 4.13.0, JSON Schema draft 2020-12, Node test runner, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-23-scan-web-design.md`

## Global Constraints

- Preserve every existing `capture-web-evidence.mjs` CLI argument and output field.
- Do not change audit-run, artifact-envelope, screening-observation, or assessment schema versions in this slice.
- Do not convert machine passes or violations into profile outcomes.
- Use the existing exclusive safe writer; no output may be overwritten.
- Keep Codex and Claude skill distributions byte-equivalent for every shared file.
- Reuse the current private-address, allowed-origin, redirect, and bounded interaction controls.
- Store exact runtime engine versions in each scan.
- Full scan output is internal evidence; compact context is smaller but not automatically public-safe.

export async function withWebInspectionSession(options, inspect) {
  const requested = parseTargetUrl(options.url, options);
  await assertPublicResolution(requested, options);
  const allowedOrigins = new Set([requested.origin, ...(options.allowOrigins ?? [])]);
  const blockedRequests = [];
  const { chromium } = await loadPlaywright();
  const browser = await chromium.launch({ headless: true });

    return await inspect({ page, context, browser, requested, finalUrl, response, allowedOrigins, blockedRequests });
  } finally {
    await browser.close();
  }
}
