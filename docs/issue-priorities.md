# Issueの優先順位と実装範囲

2026-09-18時点で、未完了Issueは37件（整理用の#144を含む）、未完了PRは0件。実装の有無とIssueの完了は区別し、受け入れ条件が残るものは未完了として扱う。

最初に、人が確認した不適合を保存・報告する経路を整える。次に、その証拠から許される主張範囲を選択可能にし、中断した監査の再開に必要な状態表示を加える。
