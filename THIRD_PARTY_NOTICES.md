# Third-Party Notices and Source Provenance

The repository's MIT License covers original code and original project documentation. It does **not** automatically relicense third-party standards, translations, titles, metadata, or explanatory material that may be referenced or represented in generated catalogs.

This file is a provenance index, not legal advice. Before redistributing imported third-party material outside this repository, verify the current terms at the primary source.

## W3C accessibility specifications

- Publisher: World Wide Web Consortium (W3C)
- Examples used by this project: WCAG, WAI-ARIA, ARIA in HTML, Understanding / Techniques references
- Primary source: https://www.w3.org/
- Imported scope: identifiers, criterion titles/levels, source URLs, and project-authored mappings; the project should avoid copying specification prose when an identifier and source link are sufficient.
- Terms: verify the current W3C copyright/document-use terms at the source before redistribution.

## WAIC materials

- Publisher: ウェブアクセシビリティ基盤委員会 (WAIC)
- Primary source: https://waic.jp/
- Examples used by this project: JIS X 8341-3 related guidance, checklists, translations, and source links.
- Imported scope: requirement identifiers/titles, source URLs, and project-authored mappings where needed.
- Terms: verify the terms shown on the specific WAIC page or document. Translated W3C materials can carry source-specific conditions distinct from WAIC-authored guidance.

## Digital Agency accessibility policy

- Publisher: デジタル庁
- Primary source: https://www.digital.go.jp/accessibility-statement
- Imported scope: organization-specific accessibility-policy metadata and the additional WCAG criteria used as a reference pattern.
- Important scope note: this is an organizational policy source, not a general normative profile for every Japanese public website.
- Terms: verify the current site/content terms before redistribution.

## Contribution rule

A pull request that imports or refreshes third-party metadata must record:

1. publisher and primary URL;
2. imported fields;
3. whether the source is normative, explanatory, translated, or organization-specific policy;
4. the relevant terms/license URL when known;
5. whether attribution or redistribution constraints affect generated artifacts.

When terms are unclear, prefer storing project-authored identifiers, classifications, and source links instead of copying prose.
